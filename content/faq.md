## Is this allowed?

Spindle reads the combat log file the game writes to your disk, the same file other log tools read. It doesn't read game memory, inject anything, or give you alerts during combat.

## Do I need an addon?

No. Advanced combat logging is a game setting. The Spindle addon is optional: it turns combat logging on for you in dungeons and raids, so you don't forget.

## Does everyone in the group need Spindle?

No. One player logging captures the whole party.
